为当前项目生成或更新交接文件，方便之后重新获取上下文继续修。

要求：

1. 先判断当前目录是什么项目，读取 README、构建配置、脚本、最近修改点。
2. 交接文件优先命名为 `HANDOFF.md`；如果项目已有等价文件，沿用原文件。
3. 内容包括：
   - 项目目的和当前状态
   - 关键目录和入口文件
   - 安装/启动/测试/构建命令
   - 本机依赖和系统服务
   - 最近完成的改动
   - 演示或实机故障时的排查顺序
   - 不应提交的文件和敏感信息位置说明
4. 写完后运行项目可用的最小验证命令；无法验证时说明原因。

用户补充要求：

```text
$ARGUMENTS
```
