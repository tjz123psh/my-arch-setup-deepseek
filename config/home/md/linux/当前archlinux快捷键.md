## 十六、快捷键速查面板（`niri-keys`）

`Super+/` 打开一个浮动小窗口，显示 niri 全部自定义快捷键的分类表格。本文档已按 `niri-keys --print` 和 `~/.config/niri/dms/keybinds.kdl` 复核；如果以后改快捷键，优先以脚本输出为准再同步本文。

| 特性 | 说明 |
|---|---|
| 触发方式 | `Super+/` 或直接运行 `niri-keys` |
| 窗口类型 | kitty 浮动窗口（700×500），自动居中 |
| 数据来源 | `~/.config/niri/dms/keybinds.kdl` |
| 脚本位置 | `~/scripts/desktop/niri-keys`；命令入口 `~/.local/bin/niri-keys` |
| 显示内容 | 带中文描述的快捷键表格，按功能分类 |
| 设计特点 | 浅蓝色键名，分类间隔，光标隐藏，键盘输入无效，仅展示 |

**工作流程：**
1. niri 调用 `kitty --class=niri-keys` 启动脚本
2. 脚本自动检测是否在 kitty 中，不在则开新窗口
3. 解析 `keybinds.kdl`，提取 `hotkey-overlay-title` 行和带注释的快捷键行
4. 输出格式化的中文表格（过滤单键媒体键和工作区号）
5. 脚本挂起等待 → 点击 X 或 `Ctrl+C` 关闭

**注意：** 此脚本与 niri 内置 `Super+Shift+/` 不同——内置显示原始 KDL 格式的快捷键覆盖层，此脚本显示整理后的中文分类表格。

> **Hyprland 备用环境：** 同机的 Hyprland 会话有平行的速查面板 `hypr-keys`，同样 `Super+/` 触发、kitty 浮动窗口（700×500）。区别在于 Hyprland 配置是 Lua（入口 `~/.config/hypr/hyprland.lua`，已按功能拆分到 `~/.config/hypr/conf/*.lua`，键位在 `conf/keybinds.lua`），无 KDL 可解析，故数据源改为独立清单 `~/.config/hypr/keybinds.list`；改 Hyprland 键位后同步该清单。脚本位置 `~/scripts/desktop/hypr-keys`，命令入口 `~/.local/bin/hypr-keys`。

## VM 测试模式开关（2026-08-07 新增）

| 快捷键 | 功能 | 说明 |
|---|---|---|
| `Super+Shift+D` | 切换 VM 测试模式 | 在 VMware 里测试与 host 同款键位的系统时使用：**进** = host 快捷键全关（按键全部透传 VM）；**再按一次** = 恢复 host 快捷键 |

- 测试模式只保留这一个键有效，其余键全部进入 VM；
- VM 全屏时先按 `Ctrl+Alt` 释放键盘，再按 `Super+Shift+D`；
- 相关文件：`~/.config/niri/config.kdl`（开关绑定）、`~/.config/niri/config.kdl.vmtest`（测试配置，由 `~/scripts/desktop/niri-vmtest-gen` 生成）；改过 config.kdl 后跑一次生成器刷新。
