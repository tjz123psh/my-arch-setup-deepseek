# Neovim 快捷键速查表

> leader 键 = **空格**

---

## 行操作

| 快捷键 | 模式 | 功能 |
|--------|------|------|
| `J` | 普通 | 下移当前行，支持数字前缀 |
| `K` | 普通 | 上移当前行，支持数字前缀 |
| `J` | 可视 | 向下移动整块选中行并保持选择 |
| `K` | 可视 | 向上移动整块选中行并保持选择 |
| `<leader>j` | 普通 | 合并下一行 |

## 基础操作

| 快捷键 | 模式 | 功能 |
|--------|------|------|
| `jk` | 插入 | 快速退出插入模式（better-escape.vim 处理，无延迟） |
| `jk` | 终端 | 退出终端模式回到普通模式（可能误触） |
| `s` | 普通/可视/操作符待决 | Flash 跳转（原版 `s` 改为 `xi` 或 `cl`） |
| `S` | 普通/可视/操作符待决 | Flash Treesitter 选择（原版 `S` 改为 `cc`） |
| `<C-s>` | 普通/插入 | 保存当前文件 |
| `<C-CR>` | 插入 | 在下方新建空行，继续编辑 |
| `<leader>hk` | 普通 | 打开/关闭个人快捷键速查浮动窗口（`q`/`Esc` 关闭） |
| `<Space>` | 普通 | Leader 键，等待后续命令 |

## 窗口操作

| 快捷键 | 功能 |
|--------|------|
| `<C-h/j/k/l>` | 切换到左/下/上/右窗口 |
| `<leader>sh` | 水平切分窗口 |
| `<leader>sv` | 垂直切分窗口 |
| `<leader>q` | 关闭当前窗口 |

## 缓冲区操作

| 快捷键 | 功能 |
|--------|------|
| `<S-h>` | 切换到上一个缓冲区 |
| `<S-l>` | 切换到下一个缓冲区 |
| `<leader>ba` | 关闭其他缓冲区 |
| `<leader>bd` | 关闭当前缓冲区（文件） |
| `<leader>wq` | 保存并关闭 |

> 提示：缓冲区（Buffer）= 内存中的文件；窗口（Window）= 缓冲区的一个视口；标签页（Tab page）= 一组窗口布局。
>
> 新增快捷键后同步到速查窗口：在 `lua/core/cheatsheet.lua` 对应分类加一行 `{ "按键", "说明" }`，按 `<leader>hk` 即可看到。
> 速查窗口会自适应宽高，并对分区和快捷键列做高亮。

## 文件树（neo-tree）

| 快捷键 | 功能 |
|--------|------|
| `<leader>e` | 打开/关闭文件树 |

**文件树内操作：** `Enter`/`o` 打开, `h` 上级, `l` 设为根, `a` 新建, `d` 删除, `r` 重命名, `m` 移动, `c` 复制, `p` 显示隐藏文件

## 搜索（telescope）

| 快捷键 | 功能 |
|--------|------|
| `<leader>ff` | 搜索文件名 |
| `<leader>fg` | 搜索文件内容 |
| `<leader>fb` | 切换已打开的文件 |
| `<leader>fh` | 搜索帮助文档 |
| `<leader>fd` | 搜索个人文档（~/md/） |
| `<leader>fp` | 搜索项目（走 `:Projects`，首次打开会同步读取项目历史） |
| `<leader>fc` | 搜索配置 |

搜索界面内：`<C-j>` 向下选择，`<C-k>` 向上选择

## 代码导航（LSP）

| 快捷键 | 功能 |
|--------|------|
| `gd` | 跳转到定义 |
| `gR` | 跳转到类型定义 |
| `gr` | 查找引用 |
| `gi` | 跳转到实现 |
| `gh` | 悬停显示文档 |
| `[d` / `]d` | 上一个/下一个诊断（使用 `vim.diagnostic.jump`，并弹出浮动诊断） |

## 代码操作

| 快捷键 | 功能 |
|--------|------|
| `<leader>rn` | 重命名符号 |
| `<leader>ca` | 代码操作（自动修复） |
| `<leader>F` | 格式化代码 |
| `<C-k>` | 显示函数签名 |

> 保存时自动格式化：显式配置的格式化器优先，找不到工具时再走 LSP 兜底。

## 补全（blink.cmp）

| 快捷键 | 功能 |
|--------|------|
| `Enter` / `Tab` | 选中当前项 |
| `Tab` / `Shift-Tab` | 补全菜单关闭时，向后/向前跳转片段占位符 |
| `<C-n>` / `<C-p>` | 选择下一项/上一项 |
| `<C-e>` | 关闭补全菜单 |
| `<C-u>` / `<C-d>` | 文档上翻/下翻 |

## 注释

| 快捷键 | 模式 | 功能 |
|--------|------|------|
| `gcc` | 普通 | 注释/取消注释当前行 |
| `gc` | 可视 | 注释/取消注释选中行 |

## 调试（DAP）

| 快捷键 | 功能 |
|--------|------|
| `<leader>dl` | 重跑上次调试 |
| `<leader>db` | 断点列表（telescope） |
| `<leader>dB` | 条件断点（输入条件） |
| `<leader>dL` | 日志断点（输入日志） |
| `<leader>dC` | 清除所有断点 |
| `<F5>` | 开始调试 / 继续执行 |
| `<F9>` | 切换断点 |
| `<F10>` | 单步跳过 |
| `<F11>` | 单步进入 |
| `<F12>` | 单步跳出 |

**C/C++ 调试：** `g++ -g main.cpp -o main` → `<F9>` 设断点 → `<F5>` 输入可执行文件路径

**Java 调试：** `<F9>` 设断点 → `<F5>` 输入主类名（如 `Hello`）

## Java 专用

| 快捷键 | 功能 |
|--------|------|
| `<leader>co` | Java 代码操作 |
| `<leader>ot` | 整理 import |

## 终端（toggleterm）

| 快捷键 | 功能 |
|--------|------|
| `<leader>tt` | 切换浮动终端 |
| `<leader>th` | 水平分割终端 |
| `<leader>tv` | 垂直分割终端 |

`jk` 退出终端模式回到普通模式（复用 keymaps.lua 的终端退出）。

## 自定义命令

| 命令 | 用途 |
|------|------|
| `:R` | 重新加载当前 `.lua` 配置 |
| `:A` | 返回启动欢迎页 |
| `:LspInfo` | 查看 LSP 客户端状态 |
| `:LspLog` | 打开 LSP 日志文件 |
| `:Projects` | 打开项目列表，回车切换项目并刷新文件树 |
| `:JavaInit` | 在 Java 包根目录生成 jdtls 用的最小 `pom.xml` 标记 |
| `:JavaRun` | 运行当前 Java 源文件，支持 package 目录结构和按需源码依赖 |
