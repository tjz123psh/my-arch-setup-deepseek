# 从零搭建 Neovim 环境 — AI 依赖清单

> 把 nvim 配置文件丢给 AI 前，先确保以下系统依赖已就位。

## 必要（不装 nvim 不能正常使用）

```bash
sudo pacman -S base-devel git ripgrep fd neovim
```

| 包 | 谁在用 | 说明 |
|----|--------|------|
| `base-devel` | mason 预编译工具 | C/C++ 编译链（clangd/codelldb 需 glibc） |
| `git` | lazy.nvim | 下载和管理插件（lazy.nvim 首次启动自动克隆自身） |
| `ripgrep` | telescope | 搜索文件内容的引擎，缺了会报错 |
| `fd` | telescope | 搜索文件名的引擎，缺了降级 `find`（慢但能用） |
| `neovim` | — | 本体，当前 **0.12.4** |

### 终端

- **Nerd Font**（JetBrainsMono Nerd Font）— 否则图标显示为方块
- **fc-match/fontconfig** — Neovide 字体检测使用；Arch 上通常由桌面环境依赖提供
- 配置文件中**显式禁用了**以下 provider 以避免告警：node、python3、perl、ruby

## 开发语言 — 按需

### Java（JDK 21）

```bash
sudo pacman -S jdk-openjdk
```

**jdtls 必须 JDK 17+**，当前机器使用 JDK 26。jdtls 启动失败不会报错，表现为 Java 文件打开后补全/跳转/调试静默失效。

自定义命令额外依赖：

| 命令 | 需要 | 功能 |
|------|------|------|
| `:JavaInit` | 无额外命令 | 在 Java 包根目录写入最小 `pom.xml`，只作为 jdtls 项目根标记 |
| `:JavaRun` | `java`、`javac` | 终端运行当前 Java 源文件；有 package 时按需编译当前文件和依赖源码 |

### Rust

```bash
sudo pacman -Rns rust 2>/dev/null || true
sudo pacman -S --needed rustup
rustup default stable
rustup component add rust-src rustfmt clippy
rustc --version
cargo --version
rustfmt --version
clippy-driver --version
rustc --print sysroot
```

Rust DAP 调试依赖 `cargo build`（codelldb 由 mason 自动安装）。`rust-src` 用于 rust-analyzer 标准库源码跳转和更完整分析。

### Go

```bash
sudo pacman -S go
```

### C/C++

系统只需 `gcc`（`sudo pacman -S gcc`），其余由 mason 处理。

## 搭建步骤

```bash
# 1. 装系统依赖（见「必要」和「开发语言」）
# 2. 把 nvim 配置文件放到 ~/.config/nvim/
# 3. 启动 nvim → lazy.nvim 自动下载所有插件
# 4. Mason 自动安装 LSP / DAP / 格式化器（见上方清单）
# 5. 打开对应语言的 .rs / .java / .go / .cpp 验证 LSP
```

## 验证命令

```bash
nvim --headless '+qa'
nvim --headless '+checkhealth vim.lsp' '+qa'
nvim --headless '+checkhealth lazy' '+qa'
~/.local/share/nvim/mason/bin/stylua --check ~/.config/nvim/lua
```

`checkhealth vim.lsp` 不应再出现 gotmpl、markdown.mdx、yaml.docker-compose、yaml.gitlab、yaml.helm-values 的 Unknown filetype 警告。

`checkhealth mason` 可能提示 wget、luarocks、Ruby、Composer、PHP、Julia、pip 缺失；这些是 Mason 对多语言生态的可选探测。本配置当前依赖 curl、git、unzip、tar、bash、node、python、cargo、go、java/npm 等，缺少上述可选工具不影响已配置的 LSP/DAP/格式化器。
