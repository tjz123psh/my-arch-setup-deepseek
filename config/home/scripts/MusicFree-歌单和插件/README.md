## 恢复方法

1. 完全退出 MusicFree
2. 运行本目录的 `一键恢复.sh`（或双击 `恢复MusicFree插件.desktop`）
3. 重新打开 MusicFree

> 注意：MusicFree 运行时会清理插件目录，恢复前必须退出应用（脚本已自动处理）。
