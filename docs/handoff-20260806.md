## 8. 关键技术笔记（踩过的坑）

- **runuser 不带会话环境**：`runuser -u user -- systemctl --user` 必须补
  `XDG_RUNTIME_DIR=/run/user/<uid>`（334affc）
- **rustup**：conflicts=rust/cargo/rustfmt 但 provides 三者；批量装时依赖 cargo 的包
  （cargo-audit）会拉 rust 包冲突——先装 rustup（0d748aa），resume 时先清残留（b5eb639）
- **grub-mkconfig 主题**：只在 gfxterm=1 时应用 GRUB_THEME；legacy GRUB_TERMINAL 会覆盖
  INPUT/OUTPUT（serial console 配置会静默丢主题）——删 GRUB_TERMINAL + 强制 gfxterm（c93288e）
- **cp -a 到 vfat**：chown 失败返回非零中止脚本——用 cp -r（80af58e）
- **sudo 一次密码**：/etc/sudoers.d/99-install-timeout（timestamp_timeout=240）——
  普通用户首 sudo 后写入，99-cleanup 删除
- **qcow2 崩溃遗留**：refcount 损坏 qemu 自动修复（首次启动慢属正常）；
  libvirt 网络规则损坏 `systemctl restart libvirtd` 重建
